# Verita

Financial Crime & Compliance intelligence platform — FastAPI backend (`backend/`),
React + TypeScript frontend (`frontend/`). See `README.md` for architecture and quickstart.

## Design Context

Before any frontend/UI work, read:

- **`PRODUCT.md`** — register (product; landing runs brand), audiences, brand
  personality ("forensic, confident, alive"), anti-references, design principles,
  and the WCAG **AAA** accessibility bar.
- **`DESIGN.md`** — the visual system. North Star: **"The Forensic Ledger."** The
  paper/ink/stamp identity is canonical; the dark aurora/glass system in the app
  shell is legacy (maintain, don't extend). Named rules live there (Hard Shadow,
  Iron-Gall, Mono Witness, Ceremony).

`docs/design-system.md` is the superseded v2 ("luminous aurora") spec — historical
reference only; DESIGN.md wins on conflict.
