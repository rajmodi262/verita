# Day-Before Checklist

*Run top to bottom. Check boxes with a pen — the physicality matters.*

## The materials (60–90 min, daylight hours)

- [ ] `identity.tex` placeholders filled → `compile-masterpack.sh` ran green
- [ ] The grep is clean: no `[MY_PHONE]`, `[INTERVIEW_DATE]`, `[X]` anywhere
- [ ] Every PDF opened and flipped once — eyes on every page (printers eat pages silently)
- [ ] Print run collected per `PRINT-INSTRUCTIONS.md`; assembly stack built
- [ ] All PDFs copied to phone AND a cloud link that works in an incognito tab
- [ ] Business cards in jacket pocket — try the actual jacket
- [ ] Poster rolled, rubber-banded, by the door

## The demo (30 min — rehearse failure, not success)

- [ ] `start.bat` from cold boot on the laptop you're bringing — timed, working
- [ ] Demo run WITH Wi-Fi off — fallback mode confirmed honest (`/api/health`)
- [ ] `data/sample_transactions.csv` present + ONE never-before-seen CSV ready for
      the "drop yours in" offer
- [ ] Laptop charged + charger packed + phone hotspot tested as venue-Wi-Fi backup
- [ ] **Landing hero metric fixed to the honest 0.913** (see FILL-IN-THESE-PLACEHOLDERS.md
      item 1 — do not skip; HR13 tells this story as a virtue)

## The mind (20 min, evening — and then STOP)

- [ ] One read of `rapid-fire-deck.md` (the only allowed rehearsal tonight)
- [ ] One walkthrough of the bundle page order, out loud, from memory:
      *poster — comic — problem/solution — advantage — journey — constellations —
      homework — numbers — next — close*
- [ ] Opener A, B, C each said aloud once (mirror optional, recommended, ridiculous, effective)
- [ ] THE closing question said aloud once: *"...which one do you personally find
      most interesting?"*
- [ ] `if-everything-goes-wrong.md` skimmed — meet the disasters tonight so they're
      acquaintances tomorrow

## The body

- [ ] Clothes chosen, tried on, hanging
- [ ] Route planned + buffer; transport charged/fueled/booked
- [ ] Alarm set, second alarm set
- [ ] No new material after 9pm. No codebase "quick check." The repo is sealed
      tonight — like the chain.

## The one thing NOT to do

Do not rehearse answers in bed. The war room is in your spine by now; tonight's
job is sleep. The candidate who shows up rested beats the candidate who shows up
with one more memorized answer, every single time.
